# Contributing to Papertrail

Help make it easier to find files without sending them to a cloud service. Useful contributions include reproducible bug reports, accessibility improvements, import reliability fixes, and tests for additional image formats.

## Run locally

Use Python 3.12. From the repository root:

```powershell
python bootstrap.py --prepare-only
.venv\Scripts\python app.py
```

Open `http://127.0.0.1:8765`. First setup downloads dependencies; the first visual import downloads the CLIP model. See the README for storage locations and platform limits.

## Check your changes

```powershell
.venv\Scripts\python -m unittest discover -s tests -v
```

For interface changes, install Playwright in a development environment and run the browser suites described in the README. Real-model tests require the cached model and the fixtures described in `tests/FIXTURES.md`. They are separate from the core test workflow.

## Report an issue

Include what you expected, what happened, your OS/Python version, and the smallest reproduction you can share. A generated sample document or public test photo is best. Remove personal details from screenshots and logs. Never attach your `.papertrail` database, private documents, credentials, or model cache.

## Send a pull request

Keep the change focused, describe its effect on the user, and explain how you checked it. Preserve local processing and existing originals. Add tests for meaningful new behavior or regressions. Do not commit `.venv`, `.models`, `.papertrail`, or generated bytecode.
