        GETTING STARTED
      

      
A home for your paper trail.

      

        Add documents using the file picker or drop them anywhere in this
        window. Files you upload are copied into local app storage.
      

      

        Import photo library reads every supported photo in a chosen folder and
        its subfolders. Turn on sync to pick up new, changed, and deleted files
        automatically while the app is running. Pause or disconnect folders from
        the Folders panel.
      

      

        Search what is in a photo: “car”, “mountains”, or “a dog on the beach”.
        Visual search runs locally using CLIP, after a one-time model download
        of about 600 MB. No photo or search is uploaded. Text search still finds
        exact words in filenames, documents, and scans.
      

      

        Visual matches are approximate, not verified labels. Specific makes and
        models can be wrong. You can switch to “Text only” or “Visual only” to
        compare results.
      

      

        Removing a file leaves the original untouched. Undo is available for two
        minutes. Synced folders respect removals. Upload the file again to
        re-add it after undo expires. Exact duplicate uploads are skipped. PDFs
        open in their original layout with page navigation; extracted text is
        also available.
